# Vendor-Agnostic Research Agent Pack (`@fl/vendor-agnostic-research-agent`)

Reference example demonstrating an FLP Agent Pack (`.flpk.yml`) with AAP v0.1 Action Descriptor bindings (`actions`) and a multi-vendor Playbook (`.flpb.yml`) using `planner`, `executor`, and `verifier` roles across Anthropic, Google Gemini, and OpenAI.
