# minimal-command

**What:** A keyboard-first UI template that hides the sidebar, floats the header, and centers the experience on the command palette.

**When to use:** Power users who prefer a clean, distraction-free interface and navigate primarily via keyboard shortcuts. Pairs well with the `be-concise` guideline for a tight, efficient experience.

**Example:**

Default layout: Full sidebar visible, large header bar, standard card density.

With template: Sidebar is hidden (togglable with a shortcut), header floats above content and fades on scroll, home view opens directly to the command palette, font is slightly smaller for more content density, and list items are compact with less whitespace.
