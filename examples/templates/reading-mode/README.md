# reading-mode

**What:** A calm, generous layout for reading long AI responses — larger text, narrower content column, minimal chrome.

**When to use:** Research, writing review, or any session where the user is consuming long-form content rather than firing off quick queries. Reduces cognitive load by removing visual clutter and widening line spacing.

**Example:**

Default layout: Normal density, full-width chat, standard font size — feels productive but can be fatiguing over long reading sessions.

With template: Content column narrows to 44rem (optimal reading width), font scales up 10%, cards have soft shadows instead of flat borders, and the header collapses to a minimal strip. The result feels closer to reading a document than using a chat interface.
