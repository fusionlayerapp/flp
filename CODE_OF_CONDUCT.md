# Code of Conduct

## Our standard

Be respectful, constructive, and honest. We are building open infrastructure — keep discussion focused on the technical merits of proposals.

## Unacceptable behaviour

- Harassment, personal attacks, or discrimination of any kind.
- Publishing private information without consent.
- Sustained disruption of project discussions.

## Enforcement

Violations can be reported to the project steward (see [GOVERNANCE.md](GOVERNANCE.md)). Reports will be handled confidentially. The steward may close issues, remove comments, or restrict access as appropriate.

## Scope

This code of conduct applies to all project spaces: GitHub issues, PRs, discussions, and any official communication channels.
